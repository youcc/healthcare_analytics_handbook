# Hard Skills

Healthcare analytics engineers combine technical depth with healthcare domain context. The chapters in this section cover the core technical skills you need to be effective: SQL for querying and transforming clinical and claims data, Python and R for analysis and modeling, and data visualization for communicating findings to clinical and operational stakeholders.

What makes these skills different in healthcare is not the tools themselves — it is knowing *what* to query, *why* a metric is defined a certain way, and *how* to handle the regulatory and data quality constraints specific to healthcare. These chapters address both the technical mechanics and the healthcare-specific context.
